# AI Auto Service

Վարորդը chat-ում նկարագրում է մեքենայի խնդիրը, AI-ը գտնում է ծառայությունը և գարաժները (գնով, ժամերով), իսկ վարորդը կարող է թողնել հայտ։ Գարաժների, գների, ժամերի և հայտերի կառավարումը՝ ադմին պանելում։

## Ֆայլեր

| Ֆայլ | Դերը |
|---|---|
| `data.py` | մոդելներ + նմուշային տվյալներ |
| `db.py` | SQLite բազա (աղյուսակներ, seed, `python db.py ...`) |
| `queries.py` | ընթերցում/գրառում բազայում |
| `api.py` | FastAPI. հանրային endpoint-ներ, `/app`, `/panel` |
| `admin.py`, `auth.py` | ադմինի API, մուտք, rate limit |
| `chat.py` | AI (Claude + գործիքներ) և պարզ ռեժիմ |
| `chat.html`, `admin.html` | վարորդի chat-ը և ադմին պանելը |
| `test_api.py` | API-ի, բազայի, ադմինի, հայտերի թեստեր՝ `python test_api.py` |
| `test_ai.py` | AI-ի հանգույցի թեստ կեղծ սերվերով (բանալի պետք չէ)՝ `python test_ai.py` |
| `test_browser.py` | իրական դիտարկչով թեստ (`pip install playwright && playwright install chromium`)՝ `python test_browser.py` |

## Գործարկում ձեր համակարգչում

```
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...        # ցանկության դեպքում. առանց սրա chat-ը պարզ ռեժիմում է
uvicorn api:app --reload
```

- Chat՝ http://127.0.0.1:8000/app
- Ադմին՝ http://127.0.0.1:8000/panel (dev-ում գաղտնաբառը `admin`, եթե `ADMIN_PASSWORD` չեք նշել)
- API-ի փաստաթղթեր՝ http://127.0.0.1:8000/docs

## Փոփոխականներ

| Անուն | Նշանակություն |
|---|---|
| `ADMIN_PASSWORD` | ադմինի գաղտնաբառ (production-ում պարտադիր) |
| `SECRET_KEY` | token-ների ստորագրման բանալի (production-ում պարտադիր) |
| `ANTHROPIC_API_KEY` | AI-ի բանալի. դատարկ՝ պարզ ռեժիմ |
| `ANTHROPIC_MODEL` | մոդելի անուն (լռելյայն՝ `claude-sonnet-5-5`) |
| `AUTOSERVICE_DB` | բազայի ֆայլի ճանապարհ |
| `SEED_SAMPLE` | `1`՝ նմուշային գարաժներ առաջին գործարկման ժամանակ, `0`՝ դատարկ բազա |
| `APP_ENV` | `production`՝ առանց գաղտնաբառի սերվերը չի սկսվում |

## Տեղակայում (Docker)

```
docker build -t autoservice .
docker run -d -p 8000:8000 -v autoservice-data:/data --env-file .env autoservice
```

`/data` volume-ը պարտադիր է. այնտեղ է բազան, առանց դրա տվյալները կկորչեն կոնտեյները թարմացնելիս։ Ծառայությունը կարելի է դնել Render, Railway, Fly.io կամ սովորական VPS-ի վրա. կարևոր է միացնել HTTPS (այս հարթակների մեծ մասը դա անում է ինքնուրույն) և persistent disk/volume։

**Backup.** բազան մեկ ֆայլ է (`autoservice.db`). պարբերաբար պատճենեք այն։

## Իրական գարաժի հետ փորձարկման ցուցակ

1. Գործարկեք `SEED_SAMPLE=0`-ով, որպեսզի նմուշային գարաժներ չլինեն։
2. Ադմին պանելում ավելացրեք իրական գարաժը, ծառայությունները, գները, ժամերը։ Ստուգեք տվյալները գարաժի սեփականատիրոջ հետ։
3. Ստուգեք chat-ը տասը իրական վարորդական նկարագրությամբ. ինչ չի գտնվում, ավելացրեք որպես ծառայություն կամ բանալի բառ։
4. Գարաժի աշխատակիցը պետք է օրական մի քանի անգամ բացի «Հայտեր» էջը (ծանուցումներ դեռ չկան)։
5. Հետևեք AI-ի ծախսին Anthropic Console-ում. chat-ը սահմանափակված է 20 հարցում/րոպե մեկ IP-ից։

## Ինչ դեռ չկա

- **Գրանցում ժամին** (սլոթեր). այժմ միայն հայտ է, և գարաժը զանգահարում է վարորդին։
- **Ծանուցումներ** (Telegram/SMS) նոր հայտի մասին։
- **Յուրաքանչյուր գարաժի իր մուտքը.** այժմ մեկ ընդհանուր ադմին գաղտնաբառ է։
- **Մեկից ավելի սերվեր.** SQLite-ը հարմար է մեկ սերվերի և փոքր ծանրաբեռնվածության համար. աճի դեպքում անցեք PostgreSQL-ի։
- `--proxy-headers`-ը վստահում է `X-Forwarded-For`-ին. եթե սերվերը հասանելի է ուղղակիորեն առանց proxy-ի, IP-ի սահմանափակումը հնարավոր է շրջանցել։

## Անվճար դեմո Render-ում

1. Ստեղծեք GitHub հաշիվ և **նոր private repository**։ Վերբեռնեք այս թղթապանակի ֆայլերը **repository-ի արմատում** (`api.py`, `render.yaml` և մնացածը՝ ոչ թե ենթաթղթապանակում)։ `.gitignore`-ը արդեն կա։
2. render.com → գրանցվեք GitHub-ով (քարտ պետք չէ) → **New → Blueprint** → ընտրեք repository-ն։
3. Render-ը կհարցնի `ADMIN_PASSWORD`. մուտքագրեք երկար գաղտնաբառ։ Սեղմեք **Apply**։
4. 3-5 րոպե հետո կստանաք հասցե՝ `https://ai-auto-service-xxxx.onrender.com`։ Chat՝ `/app`, ադմին՝ `/panel`։

**Ինչ պետք է իմանալ**
- 15 րոպե անգործությունից հետո սերվերը քնում է. հաջորդ բացումը 30-60 վայրկյան է։ **Դեմոյից 2 րոպե առաջ բացեք հղումը հեռախոսից։**
- Ամեն քնելիս/վերագործարկելիս տվյալները վերադառնում են նմուշային վիճակին (ադմինի փոփոխությունները և հայտերը ջնջվում են)։ Դեմոյի համար սա հարմար է, իրական գարաժի համար՝ ոչ (տե՛ս ստորև)։
- AI-ը միացնելու համար Render → Environment → ավելացրեք `ANTHROPIC_API_KEY`։ Օրական սահմանը՝ `AI_DAILY_LIMIT` (100). անցնելիս chat-ը անցնում է պարզ ռեժիմի։ Դեմոյի համար լավ է Anthropic Console-ում սահմանել նաև ծախսի սահման։

**Իրական գարաժի համար** անվճար պլանը չի պիտանի, քանի որ տվյալները չեն պահվում։ Անհրաժեշտ կլինի վճարովի instance persistent disk-ով (հիմա ամսական մի քանի դոլար, ստուգեք render.com/pricing) և `AUTOSERVICE_DB=/data/autoservice.db`, `SEED_SAMPLE=0`։
